Supabase Belum Dikonfigurasi

Admin CMS ini butuh koneksi ke Supabase supaya bisa nyimpen perubahan. Isi SUPABASE_URL dan SUPABASE_ANON_KEY di js/supabase-config.js, lalu tambahkan script CDN Supabase di admin.html (lihat komentar di dalam file itu).

Sampai itu diisi, website utama tetap jalan normal pakai data dari js/data.js.
